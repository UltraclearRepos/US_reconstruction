# Ultrasound reconstruction pipeline

Pipeline converts a 2D ultrasound sweep into an intensity volume or a
reconstructed 3D segmentation. Technical parameters are in `config.py`;
the cases, selected route and `RUN_*` switches are at the top of `main.py`.
All implementation packages live under `src/`.

## Data contract

`case` always means the acquisition name. Processing variants are represented
by directories, never by suffixes added to the case name.

```text
data/
├── raw/<case>/*.dcm
├── prepared/<case>/sweep.h5
├── denoised/<case>/<denoising_method>/sweep.h5
├── segmented/<case>/
│   ├── prepared/<model>/labels.h5
│   └── denoised/<denoising_method>/<model>/labels.h5
├── reconstructed/
│   ├── intensity/<case>/<source...>/<method>/volume.npz
│   └── segmentation/<case>/<source...>/<model>/voxel_nearest/labels.npz
├── ground_truth/<case>/
│   ├── volume.npz
│   └── labels.npz
└── surfaces/
    ├── ground_truth/<case>/
    └── predicted/<case>/<source...>/<model>/voxel_nearest/

runs/unsupervised/<case>/<source...>/<run>/
reports/evaluation/{intensity,segmentation,no_reference}/
models/segmentation/<model>/
```

A source is either:

- `prepared`
- `denoised/<denoising_method>`

Every sweep-like H5 contains frames or labels with shape `(N,H,W)`, probe
poses `(N,4,4)`, and pixel spacing. Each stage writes one canonical artifact;
NPZ and per-class H5 copies are not created.

## Selecting a route

Set the cases and downstream input at the top of `main.py`:

```python
CASE_NAMES = ["kosartur"]
INPUT_SOURCE = "denoised"       # "prepared" or "denoised"
INPUT_DENOISING_METHOD = "rdpad"
```

Then enable only the stages that should run:

```python
RUN_PREPARE_DATA = True
RUN_DENOISING = True
RUN_SUPERVISED_SEGMENTATION = True
RUN_RECONSTRUCT_INTENSITY = True
RUN_RECONSTRUCT_SEGMENTATION = True
RUN_ISOSURFACE_EXTRACTION = True
```

Stages do not have to run in one invocation. For example, reconstruction can
read an existing segmentation with the earlier switches disabled.

Choose standardized segmentations used downstream:

```python
SEGMENTATION_RESULT_MODELS = ["rdpad"]
# or:
SEGMENTATION_RESULT_MODELS = ["unsupervised_crf"]
```

Unsupervised runs are stored under `runs/unsupervised` and imported into the
same `data/segmented/.../labels.h5` contract as supervised results. Each run
gets a timestamped directory and does not delete an earlier run.

Multiclass segmentation uses `voxel_nearest` reconstruction. Averaging
methods are intentionally reserved for intensity because averaging class IDs
would create invalid labels.

Run:

```bash
.venv/bin/python main.py
```

Evaluation is terminal output, not input data, and is therefore written under
`reports/evaluation`. Ground truth is prepared only from separately supplied
DICOM Volume and Segmentation files; it is never generated by a model.
